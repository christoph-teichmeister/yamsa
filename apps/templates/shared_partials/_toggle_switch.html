{% comment %} Switch-styled checkbox. The input stays a real, hit-testable checkbox (opacity 0, stretched over the track) rather than an `sr-only` one, so it keeps working for keyboard, screen readers and Playwright's `check()`. Parameters: toggle_id id of the input (required) toggle_name form field name — omit for a read-only display switch toggle_checked checked state toggle_editable omit for a switch that only displays state and cannot be flipped toggle_aria_label accessible name when no visible
