{% load i18n %} {% comment %} The save row of a sheet, directly after the last editable section. Both buttons render enabled on purpose: a disabled submit would leave the sheet unsubmittable whenever sheet.js never runs, which is the one state the server cannot detect. The bundle disables them as soon as it has the pristine snapshot and re-enables them the moment a field differs from it. Parameters: save_button_id id of the submit button (required) discard_button_id id of the discard button (required) {% endcomment %}
