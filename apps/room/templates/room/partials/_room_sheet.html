{% load i18n room_tags %} {% comment %} The room as one continuous sheet: identity header, then a labelled row per setting. Reading and editing are the same markup — every value is already its own form control, locked until the sheet switches to edit mode, so entering edit mode needs no request and nothing moves on screen. `sheet.js` flips `data-sheet-mode` and unlocks the controls; the `tw:reading:` / `tw:editing:` variants show the matching actions. Saving posts the sheet and swaps it back in place, so RoomEditView must answer with this partial. `room_is_editing` keeps the server-rendered state in sync with the client one. A closed room has nothing to edit, so it offers no edit mode at all — only the status section, which runs on its own cycle and is therefore reachable in both modes. {% endcomment %}
